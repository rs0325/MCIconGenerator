# MCIconGenerator

Minecraft Java Editionの元テクスチャと、インベントリ表示の透過PNGを取得する開発者向けCLI・Javaライブラリです。対象は1.13以降の正式版です。

開発中です。全51版への対応と描画の再現性はまだ完成していません。設計・進捗は[Issue #1](https://github.com/rs0325/MCIconGenerator/issues/1)で管理しています。
